## Reporting a Vulnerability / الإبلاغ عن ثغرة أمنية

إذا اكتشفت ثغرة أمنية في هذا المشروع، يُرجى عدم فتح مشكلة عامة (public issue).
بدلاً من ذلك، يُرجى التواصل مباشرة عبر البريد الإلكتروني:

📧 **dridi0207@gmail.com**

Please do not report security vulnerabilities through public GitHub issues. Instead, please report them directly via email to **dridi0207@gmail.com**.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact or mitigation if known.

We will acknowledge receipt within 48 hours and work on a fix promptly.
